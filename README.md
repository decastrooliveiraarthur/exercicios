# Exercícios

Repositório com os exercícios de programação que resolvo durante meus estudos, de vários temas e linguagens.

## Organização

Os exercícios ficam em pastas separadas. Cada pasta de exercício é um projeto independente, com o código dentro da própria pasta.

## Como executar

1. Clone o repositório:
```
   git clone https://github.com/decastrooliveiraarthur/exercicios.git
```
2. Abra a pasta do exercício que quiser na sua IDE.
3. Execute o programa pela classe ou arquivo principal.

## Observações

Este é um repositório de estudo, então o código reflete meu nível na época de cada exercício.
