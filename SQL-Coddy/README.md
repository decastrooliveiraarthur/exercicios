# SQL | Coddy

Soluções que escrevi para os desafios de revisão da seção **SQLite Fundamentos**
da plataforma [Coddy](https://coddy.tech). Os três exercícios usam funções de
janela e CTEs.

| Arquivo | Nível | O que pratica |
|---|---|---|
| `criaturas.sql` | Médio | CTE, subconsulta escalar, `NTILE` com `PARTITION BY` |
| `livros.sql` | Fácil | Agregações cumulativas (`SUM`, `MAX`, `MIN`, `AVG`) e `DENSE_RANK` |
| `sucata.sql` | Médio | `ROW_NUMBER`, `NTILE`, média móvel com `ROWS BETWEEN` e `DENSE_RANK` |

Cada arquivo tem comentários explicando o raciocínio da consulta.

> Os enunciados e as tabelas pertencem ao Coddy. Aqui estão apenas as minhas soluções.
