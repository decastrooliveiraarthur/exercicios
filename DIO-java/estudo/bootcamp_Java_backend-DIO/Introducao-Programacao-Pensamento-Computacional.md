# Novos Conceitos Aprendidos ou Relembrados
### Quatro Pilares Fundamentais do Pensamento Computacional:
 1. **Decomposição:** Decompor um problema complexo em problemas mais simples;
 2. **Padrões:** Identificar padrões em estruturas similares;
 3. **Abstração:** Focar no essencial para solucionar o problema;
 4. **Algoritmos:** Criar uma série de regras que juntas solucionam o problema;
 
### Características de Qualidade de um Programa:
 - Clareza e Legibilidade
 - Eficiência e Desempenho
 - Confiabilidade e Robustez
 - Portabilidade
 - Manutenibilidade
 
### Paradigmas de Programação:
Diferentes linguagens de programação possuem diferentes regras e estruturas para escrever códigos e criar soluções. O **Java**, por exemplo, utiliza a orientação a objetos (POO).
