### O que são Git e Github
 - **Git** é um sistema de versionamento de código distribuído. Cada cópia local contém o histórico completo do projeto, o que permite trabalhar offline e torna o fluxo mais rápido e resiliente.
 - **Github** é uma plataforma que hospeda repositórios remotos feitos com o git. É por ele que é possível sincronizar (via push/pull) e expor um repositório para várias pessoas, assim como elas também podem contribuir para o repositório.
 
### Comandos Básicos de Git e Github:
 - git init;
 - git add, git add .;
 - git commit -m;
 - git status;
 - git remote add origin;
 - git push origin main, git push origin master;
 - git pull origin main, git pull origin master;
