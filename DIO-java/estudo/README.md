# Resumo de Estudos

Repositório com anotações e resumos do que estou estudando no momento fora da faculdade. Feito como parte de um desafio de projeto proposto pela DIO (Digital Innovation One).

## O que tem aqui

Cada pasta representa um curso, bootcamp ou plataforma de estudo, com arquivos `.md` resumindo os principais conceitos aprendidos.

- **`bootcamp_Java_backend-DIO/`** — Anotações do bootcamp de Java Backend da DIO: pensamento computacional, Git e GitHub, entre outros tópicos do percurso.
- **`SQL-SQLzoo-Coddy_Tech/`** — Anotações de SQL, estudado através das plataformas SQLzoo e Coddy Tech.

## Objetivo

Manter um registro organizado do meu aprendizado, servindo tanto de material de revisão pessoal quanto de portfólio do que venho estudando.
